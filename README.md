# ETRIVIUM IAM — Tema 2

**La Constitución Española (II): La Organización territorial del Estado. Principios generales. La Administración Local. Las Comunidades Autónomas: los Estatutos de Autonomía.**

Material de estudio para la oposición **C1 — Técnico Auxiliar TIC del Ayuntamiento de Madrid** (temario BOAM 10.032).

## Contenido

- **`index.html`** — web autosuficiente (offline) con 7 pestañas: Inicio, Contenido, Diagramas, Test, Casos, Validación y Fuentes. Incluye motor de test con corrección automática y penalización 1/3.
- **`tema-2-indice.md`** — índice y datos clave.
- **`tema-2-contenido.md`** — contenido teórico (12 secciones).
- **`tema-2-diagramas.md`** — 12 diagramas SVG.
- **`tema-2-test.md`** — 150 preguntas tipo examen + 20 pedagógicas.
- **`tema-2-caso-practico.md`** — 6 casos prácticos aplicados a Madrid.
- **`tema-2-fuentes.md`** — registro normativo.
- **`tema-2-validacion.md`** — checklist de validación (María / Ana).
- **`tema-2-changelog.md`** — historial de versiones.

## Estado

**v1.0 — Pendiente de validación** por el IAM (María / Ana).

## Cómo regenerar el `index.html`

El `index.html` se **genera** a partir de los `.md` con el script `build_t2.py` (mantiene sincronizados HTML y fuentes). Editar los `.md` y volver a ejecutar el generador.
